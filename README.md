# 🏦 Bank-Account-System

**Автор:** Ерников Вадим

## 📝 Описание
Консольное приложение для управления банковскими счетами с поддержкой различных типов счетов, транзакций и переводами между счетами. Реализовано с использованием паттерна MVC, JSON для хранения данных и очереди для истории транзакций.

## ✨ Функционал
- **Типы счетов:**
  - Расчетный счет (с овердрафтом)
  - Сберегательный счет (с начислением процентов)
  - Кредитный счет (с кредитным лимитом)
- **Операции:**
  - Открытие/закрытие счетов
  - Пополнение и снятие средств
  - Перевод между счетами
  - Начисление процентов
- **История транзакций:**
  - Хранение в очереди (FIFO)
  - Фильтрация по дате и типу
- **Сохранение данных:**
  - JSON сериализация
  - Автозагрузка при запуске

## 🛠 Технологии
- Python 3.9+
- JSON для хранения
- ООП (наследование, инкапсуляция, полиморфизм)
- Паттерн MVC
- Очереди (deque)
